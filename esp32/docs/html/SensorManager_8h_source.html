50/*! Reads the current value for the given sensor

52 * @return SMGR_RESULT::SMGR_SUCCESS Reading was successfull and data is stored

54 * @return SMGR_RESULT::SMGR_UNKNOWN_SENSOR No sensor with sensor_id was found
55 * (Note: reading will not get initialized)
56 * @return SMGR_RESULT::SMGR_IO_ERROR We could not read from the sensor
