SMGR_RESULT calibrate_air ( uint32_t sensor_id)

Starts calibration for air-measurement To calibrate the sensor we need to measure different "environments" to be able to correct noise and stuff like this while calculating the humidity. This calibration is meant for no water at all (= "sensor in the air")

Parameters
sensor_idThe id of the sensor we want to calibrate
Returns
SMGR_RESULT::SMGR_SUCCESS Calibration was successfull
SMGR_RESULT::SMGR_UNKNOWN_SENSOR No sensor with sensor_id was found
SMGR_RESULT::SMGR_IO_ERROR We could not read from the sensor hardware-wise
