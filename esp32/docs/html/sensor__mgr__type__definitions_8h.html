Operation result codes.

Enumerator
SMGR_SUCCESS 

Everything went as expected.

SMGR_IO_ERROR 

The sensor is not readably due hardware-failure.

SMGR_UNKNOWN_SENSOR 

The sensor with the given id is not registered for handling.

SMGR_MISSING_CALIBRATION 

Calibration-data for sensor is missing.

SMGR_CATASTROPHIC_FAILURE 

Something went terribly wrong, so we could not recover from it.

SMGR_CALLBACK_ALREADY_ASSIGNED 

Try to subscribe to an already assigned callback.

SMGR_UNKNOWN_ERROR
